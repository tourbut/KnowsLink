## 선택지 결정

선택지는 ‘웹 / Grok Bot / Dots / Claude Code 작업 세션 / 지원 확인이 필요한 호스트’ 다섯 개다. 5번은 Codex·Hermes Agent·그 밖의 호스트를 묶고 웹 사용으로 안내한다. 대상이 아닌 호스트 이름과 설치 명령은 넣지 않는다. 세션 연결(`/knowslink-session on`)을 서버가 신뢰할 수 있게 관측하지 못하면 웹은 ‘앱에서 확인 필요’로 남긴다.

## O-NM-03 결정

결정: 요청자 자신의 보낸 요청 행에 ‘입력한 코드 …abcd’ 형식으로 입력 코드 끝 4자를 보인다.

| 검토 항목 | 판단 |
|---|---|
| 새 정보 공개 | 요청자가 직접 입력한 값의 일부다. 상대 이름·존재·차단 여부를 새로 알리지 않는다 |
| 존재 oracle | 현재 `internal/relay/human.go:requestFriend`는 없는 코드에도 구별할 수 없는 placeholder 행을 만든다. 끝 4자를 모든 행에 같은 형식으로 보이면 이 성질이 유지된다. 상대의 현재 코드에서 다시 계산하면 깨지므로 금지했다 |
| 코드 노출 위험 | 친구 코드는 32바이트 무작위 값의 base64url 43자다(`store.go:randomToken`). 끝 4자는 약 24비트이며 나머지 약 232비트는 노출되지 않는다. 전체 코드는 새로 보관·표시하지 않는다 |
| 자리 수 | 4자는 일반 사용에서 서로 다른 코드를 구별하기에 충분하다. 겹치면 기존 만료 시각으로 구별한다. 자리를 늘리지 않는다 |
| 형식 밖 입력 | 4자 미만이나 base64url 밖 문자는 ‘입력한 코드 형식 다름’으로 보인다. 제어·방향 문자를 그대로 그리지 않는다 |
| 이전 요청 | 끝 4자가 없으므로 ‘이전 요청’으로 보이고 추정하지 않는다 |

보이지 않는 안도 검토했다. 그 경우 요청자가 잘못 보낸 요청을 골라 취소할 수 없다. 공개 위험이 없으므로 표시를 택했다.

## 검증

- 정본 문서 lint: 아래 완료 보고와 worker_done에 명령·종료코드를 기록한다.
- 실행하지 않은 것: 화면 렌더, 실제 호스트 설치·왕복, DEV 구현 가능성 검토. 보관 방식은 DEV가 정한다.
