## 사용자 요구 (2026-10-17 직접 지시)

1. Claude Code에도 KnowsLink를 설치할 수 있게 한다.
2. Claude Code 세션에서 `knowslink on`을 하면 그 세션에서 KnowsLink가 활성화된다. 사용자가 켜지 않은 세션은 연결하지 않는다(SP-01 명시 선택). 끄는 방법(`knowslink off` 등)도 함께 제공한다(SP-09 연결 해제).
3. 활성화된 그 세션에서 친구와 메시지를 보내고 받는다.
4. 메시지가 도착하면 Claude Code mod를 이용해 toast로 알린다. toast는 도착 알림이며 '세션 수신 확인'과 구분한다(설계의 상태 구분).

`knowslink on`의 실제 형태(슬래시 명령 /knowslink on, 스킬, 명령어 등)와 mod 구조는 DEV가 Claude Code 문서와 plugin-authoring 스킬을 확인해 정한다. Claude Code 문서는 claude-code-guide 또는 공식 문서로 확인한다.
